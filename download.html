Get JARVIS
Download

Install JARVIS.

Free. Windows 10/11 or macOS 11+. About five minutes, most of it automatic.

Request the installer

JARVIS is shared personally. Fill in a short form and you'll get the installer by email.

Unzip JARVIS

Extract the zip anywhere, for example your Documents folder.

Install Python 3.12

From python.org, ticking Add Python to PATH. Then, in the JARVIS folder, run py -3.12 -m pip install -r requirements.txt.

Start JARVIS

Double-click Start JARVIS.bat. Paste a free Gemini key from aistudio.google.com when asked.

Connect your accounts

Click the share icon at the top, then CONNECT next to Gmail or Instagram. Sign in in the popup and you're done.

Unzip JARVIS

Double-click the zip in Downloads.

Run the installer

Right-click Install JARVIS (Mac).command and choose Open, then Open again. macOS asks the first time because it isn't from the App Store.

Wait a few minutes

It installs Python and everything else in your user folder, with no admin password, and puts JARVIS in Applications.

Allow access

Allow the Microphone. For Autopilot: System Settings › Privacy & Security › Accessibility and Screen Recording › turn on JARVIS.

Install the APK

Copy JARVIS-Remote.apk to your phone and open it. Allow "install unknown apps" for your file manager.

Open Remote Control on the PC

In JARVIS, press Remote Control. It shows a Home Wi-Fi address, an Anywhere address and a pairing code.

Connect

Type the Anywhere address in the app, trust the certificate once, and enter the 8-character code. Then tap the call button to talk.

Requirements

What you need

A computer

Windows 10/11 or macOS 11+, 8 GB RAM recommended, a microphone and speakers.

A Gemini key

Free from Google AI Studio. JARVIS uses it to think and speak.

Optional

Google account for Gmail and YouTube. Instagram must be a Business or Creator account linked to a Facebook Page.
